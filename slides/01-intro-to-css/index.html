The basics

HTML gives a web page its structure

HTML (HyperText Markup Language) uses tags to tell the browser what each part of the page is.

<a href="https://www.facebook.com">Facebook</a>
Tag — the name inside angle brackets: <a>, <p>
Attribute — extra info, written in the opening tag as name="value"
Element — the whole thing: opening tag + content + closing tag

Page structure

Every page has the same skeleton

<head> = information about the page. The <title> shows on the browser tab.
<body> = everything you can see: headings, text, images, forms…

Syntax

Anatomy of a CSS rule

h1 { color: blue; font-size: 40px; }
Read it like a sentence:
"Find every <h1> → make its color blue and its font-size 40px."

Syntax

The 6 rules of writing CSS

  1. A colon : between property and value
  2. A semicolon ; after every declaration
  3. Curly braces { } around the declarations
  4. No space between number and unit: 40px, not 40 px
  5. American spelling: color, center (not colour, centre)
  6. Comments: /* like this */ (HTML used <!-- -->)

The "cascading" part

Three rules, one heading. Which color wins?

Q1. What color is "Namaste!"?
Namaste! Red. The inline style is closest to the element.
Q2. Delete style="color: red;". Now?
Namaste! Green. <style> comes after <link>, so it is read last.
Rules: ① inline beats stylesheets ② same selector → the last rule wins ③ #id beats .class beats element

Selectors

Selectors: choosing what to style

SelectorCSSSelects in HTML
Elementp { }every <p>
Class.highlight { }every tag with class="highlight"
ID#main-title { }the one tag with id="main-title"
Grouph1, h2 { }every <h1> and every <h2>
Universal* { }every element on the page
Element, class and ID cover almost everything you need as a beginner.

Selectors

Class vs ID

.class → many elements

Like your batch / section: many students share it.

#id → one element only

Like your roll number: no one else has it.

In HTML: no dot or hash, class="highlight". In CSS: add . for class and # for id.

Debugging

"My CSS isn't working!" Check these first

colour: red;→color: red;American spelling
text-align: centre;→text-align: center;American spelling again
font-size: 20 px;→font-size: 20px;no space before the unit
color = red;→color: red;use a colon, not an equals sign
color: red font-size: 20px;→color: red; font-size: 20px;a missing ; breaks the next line too
intro { … }→.intro { … }a class needs a dot in CSS
<p class=".intro">→<p class="intro">…but no dot in HTML
<link href="style.css">→<link rel="stylesheet" href="style.css">rel is required; check the path too
